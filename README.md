# Синтаксический анализ с использованием регулярных выражений
На вход программы подаётся единственная строка символов. Данная строка задает присваивание переменной значения арифметического выражения в виде:

`ПЕРЕМЕННАЯ = ВЫРАЖЕНИЕ`

Выражение может включать:  
- знаки сложения и умножения («+» и «»);  
- круглые скобки («(» и «)»);  
- константы (например, 5; 3.8; 1e+18, 8.41E–10);  
- имена переменных.

Программа с помощью регулярного выражения строит дерево, соответствующее заданному во входном файле выражению и выдаёт для данного выражения:  
1. таблицу имен;  
2. неоптимизированный код;  
3. оптимизированный код.

Написанная программа читает входные данные из текстового файла (input.txt), и выдаёт результат работы в текстовый файл (output.txt).
